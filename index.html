El santo del año

Señor, regálame al santo que necesito para este año.

Santos recibidos

    Ver todos los nombres
    No es una predicción ni un oráculo: es un gesto devocional de confianza en la Providencia, para acompañar el año con la intercesión de un santo. La lista es una selección representativa de santos, beatos, venerables y siervos de Dios; en la Iglesia hay miles de causas. Algunas frases se atribuyen por tradición. Lista revisada con noticias hasta noviembre de 2026. El estado de cada causa puede cambiar: para datos oficiales, consulta el Dicasterio para las Causas de los Santos.
